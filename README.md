# QR Converter

[![Python](https://img.shields.io/badge/Python-3-3776AB?style=flat-square&logo=python&logoColor=white)](https://www.python.org/)
[![Tkinter](https://img.shields.io/badge/GUI-Tkinter-555555?style=flat-square)](https://docs.python.org/3/library/tkinter.html)
[![Platform](https://img.shields.io/badge/Clipboard-Windows-0078D4?style=flat-square)](#requirements)

A minimalist dark-themed desktop tool that turns any text or URL into a QR code you can save or paste straight into another app. The interface is in Turkish.

## Features

- **Instant generation:** type text or a URL, then press <kbd>Enter</kbd> or click the generate button.
- **Clipboard copy:** copy the image and paste it into any app with <kbd>Ctrl</kbd>+<kbd>V</kbd> (Windows only).
- **File export:** save as PNG or JPEG.
- **Portable build:** a ready-to-run `QR_Olusturucu.exe` is included in the repository.

## Getting started

### Option 1: Run the Windows executable

Download [`QR_Olusturucu.exe`](QR_Olusturucu.exe) and open it. Nothing else needs to be installed.

### Option 2: Run from source

#### Requirements

- Python 3 with Tkinter (bundled with the standard Windows installer)
- `pywin32` for clipboard support. It is Windows-only; on other systems the app runs, but the copy button shows an error.

```bash
git clone https://github.com/yigittozdemirr/qr-converter.git
cd qr-converter
pip install "qrcode[pil]" Pillow pywin32
python main.py
```

## Build the executable

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name QR_Olusturucu main.py
```

The result is written to `dist/QR_Olusturucu.exe`.
